# Hardware

Documentación de hardware del sistema.

Subáreas previstas:

- `electrical/`: esquemas, cableado y cuadros.
- `mechanical/`: documentación mecánica relevante.
- `datasheets/`: referencias y hojas de datos.
- `bom/`: lista de materiales y revisiones.

No se deben considerar definitivas las asignaciones eléctricas hasta que estén reflejadas también en `docs/io-map.md`.
