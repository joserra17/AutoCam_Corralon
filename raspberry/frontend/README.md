# Frontend Raspberry

Dashboard web local previsto en React + Vite.

Objetivos iniciales:

- mostrar estado general del sistema;
- mostrar estado de electroválvulas;
- permitir solicitudes manuales de apertura/cierre;
- permitir órdenes temporizadas;
- editar programaciones de riego.

El frontend no debe hablar directamente con el hardware; utilizará la API local del backend.
